# カチッとメモ 📝

iPhone標準メモのように、一覧からすぐ開いて書けるシンプルなメモアプリです。

**Version 1.0 — 2026年9月29日**

## 主な機能

- メモ一覧 → タップして編集
- 1行目を自動でタイトル扱い
- メモ検索
- フォルダ風カテゴリ
- 📌 ピン留め
- 自動保存
- 本文コピー
- このメモをTXT出力
- 全メモをまとめてTXT出力
- TXTファイル読み込み
- 削除
- iPhoneでは1画面ずつ表示
- 広い画面では2ペイン表示
- ブラウザ内保存
- オフライン対応
- ログイン・外部API・広告なし

## TXTについて

### このメモをTXT出力
選択中のメモ本文をUTF-8の `.txt` として保存します。

### 全メモTXT
保存しているメモを1つのテキストファイルにまとめて保存します。

### TXT読み込み
手元の `.txt` ファイルを新しいメモとして読み込めます。

## 保存について

メモはブラウザの `localStorage` に保存します。
ブラウザのサイトデータを削除するとメモも消えるため、
大切なメモは定期的にTXT出力しておくのがおすすめです。
